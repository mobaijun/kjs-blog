## 个性化定制首页

* 新建GitHub用户名同名仓库

> 先创建一个和自己 GitHub 同用户名的仓库，比如我的 GitHub 账号为 `mobaijun` ，我的 GitHub 地址为：`https://github/mobaijun` 那么我就需要创建一个名为 `mobaijun` 的仓库，如果你填写的是正确的，会出现绿色的提示框，提示你正在创建一个 GitHub profile，如下图所示。

![image-20210810153929067](https://cdn.mobaijun.com/qiniu_cdn/img/blog_images/image-20210810153929067.png)

> 需要注意的是：仓库的访问权限一定要设置为 `public` ，创建仓库的时候，你可以勾选一下 `Add a README file` 也可以不勾选，然后自己重新创建一个 `README.md` 文件，如果是勾选了的话，则默认的 `README.md` 文件中会有一些内容，清空掉，点击右上角的小笔头可以进行自定义内容，随便写个 “Hello World”；保存后，点击自己首页，就可以看到效果了。
