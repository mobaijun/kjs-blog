### MarkDown玩Emoji😏  😏  😏

> Emoji表情速查表[传送门]( http://emojihomepage.com/ )

* ### 通过#号控制Emoji大小

~~~markdown
# 😏
## 😏
### 😏
#### 😏
##### 😏
###### 😏
~~~



* ### 可以在代码块混入Emoji

~~~java
public class Demo {
    public static void main(String[] args) {
      // 在代码中混入Emoji
        System.out.println("😏😏😏😏");
    }
}
~~~



* ###  Emoji九宫格

|  😂   |  😏   |
|  😃   |  😣   |



* ### 斜体Emoji

~~~markdown
*😏😀😁😂🤣😃😄😅😆😉*
~~~
